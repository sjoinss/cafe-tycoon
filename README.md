# 카페 타이쿤

순수 HTML/CSS/JavaScript(바닐라, 프레임워크 없음)로 만든 브라우저 카페 경영 시뮬레이션 게임입니다.

## 실행 방법

빌드 과정 없이 정적 파일만으로 동작합니다.

```bash
# 예: 아무 정적 서버로 실행 (권장 - file:// 직접 열기는 일부 브라우저에서 제한될 수 있음)
npx serve .
```

또는 `index.html`을 브라우저로 직접 열어도 됩니다.

## 파일 구성

- `index.html` — 마크업 구조
- `style.css` — 전체 스타일 (테마 시스템 포함)
- `script.js` — 게임 로직 전체 (캔버스 렌더링, 상태 관리, 저장/불러오기 등)

## 주요 기능

- **두 가지 모드**: 직접 조작하는 일반 모드, 캐릭터가 알아서 손님을 응대하는 방치형 모드
- **하루 영업 사이클**: 실시간 5분 단위 영업일, 15일 누적 목표 달성 시 엔딩
- **레벨/평판 시스템**: 서빙 누적 수에 따른 레벨업, 평판에 따른 손님 유입
- **상점**: 재료·주방 설비·알바 고용
- **커스터마이징**: 캐릭터(플레이어/알바/손님) 이미지, 메뉴 아이콘·가격, 바닥/가구, 테마 색상, 가게 이름·아이콘을 업로드/변경 가능
- **저장/불러오기**: `localStorage` 기반 멀티 슬롯 세이브

## 조작법

- 방향키 / WASD: 이동 (Shift로 달리기, Lv.3부터 해금)
- 스페이스: 설비 근처에서 조작
- Q: 인벤토리 아이템 전환
- P: 상점 열기
